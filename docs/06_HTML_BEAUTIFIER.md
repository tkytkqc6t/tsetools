# HTML Beautifier

## Overview
Format and prettify HTML code with proper indentation and structure. Makes HTML readable and easier to maintain.

## Features
- **Auto-Format**: Indent and structure HTML code
- **Error Highlighting**: Shows HTML syntax issues
- **File Upload**: Support for `.html` files
- **Copy Results**: Copy formatted HTML to clipboard
- **Download**: Save as HTML file
- **Clear**: Reset and start over

## How to Use

### Formatting HTML

1. Navigate to **BEAUTIFY** → **HTML Beautifier**
2. Paste HTML code in the left textarea or upload a file
3. Formatted result appears on the right automatically
4. Copy or download the formatted code

## Examples

### Unformatted HTML
```html
<!DOCTYPE html><html><head><title>Sample Page</title></head><body><div><h1>Welcome</h1><p>This is a sample page.</p><ul><li>Item 1</li><li>Item 2</li></ul></div></body></html>
```

### Formatted HTML
```html
<!DOCTYPE html>
<html>
  <head>
    <title>Sample Page</title>
  </head>
  <body>
    <div>
      <h1>Welcome</h1>
      <p>This is a sample page.</p>
      <ul>
        <li>Item 1</li>
        <li>Item 2</li>
      </ul>
    </div>
  </body>
</html>
```

## Common Issues

| Issue | Cause |
|-------|-------|
| Tags not aligned | Missing closing tags |
| Incorrect nesting | Tags opened/closed in wrong order |
| Extra whitespace | Minified HTML without structure |

## Common Use Cases
- Making HTML templates readable
